# پیشنهاد افزونه‌ها برای راه‌اندازی بهاران هوم

اصل کار: یک ابزار برای هر وظیفه انتخاب کنید و از نصب افزونه‌های هم‌پوشان پرهیز کنید. قبل از نصب روی سایت اصلی، ترکیب‌ها را روی staging با خرید آزمایشی و بررسی موبایل بسنجید.

| نیاز | پیشنهاد شروع | شرط تصمیم / نکته |
|---|---|---|
| فروش | WooCommerce | زیرساخت اصلی محصولات، موجودی، سفارش، حساب و checkout است. |
| SEO | Rank Math **یا** Yoast | یکی را انتخاب کنید. برای Rank Math، schema محصول ووکامرس را از همان افزونه بگیرید؛ قالب در حضور Rank Math، schema محصول WooCommerce را دوباره چاپ نمی‌کند. پس از فعال‌سازی Rich Results و نبود schema تکراری را بررسی کنید. |
| Cache | LiteSpeed Cache روی سرور LiteSpeed؛ در غیر این صورت WP Rocket | هم‌زمان دو افزونه‌ی page cache نصب نکنید. سبد، پرداخت و حساب باید از کش صفحه‌ی عمومی مستثنا باشند؛ عدد سبد این قالب از fragment ووکامرس تازه می‌شود. |
| تصاویر | ShortPixel Image Optimizer، در صورت نیاز به WebP/AVIF و فشرده‌سازی گروهی | تنها یک image optimizer فعال کنید؛ تنظیمات فشرده‌سازی را روی عکس‌های واقعی کالا مقایسه کنید تا جزئیات محصول خراب نشود. |
| صفحه‌ساز | Elementor Pro فقط اگر تیم واقعاً صفحه‌های کمپین را با drag-and-drop ویرایش می‌کند | پوسته‌ی بهاران برای خانه، آرشیو و محصول قالب اختصاصی دارد. Theme Builder المنتور می‌تواند template محصول/آرشیو را جایگزین کند؛ برای هر نوع صفحه فقط یک template فعال بماند. |
| پشتیبانی سفارش و چند اپراتور | Fluent Support در مرحله‌ی رشد | افزونه‌ی پشتیبانی WooCommerce می‌تواند اطلاعات خرید را کنار ticket نشان دهد. در آن مرحله، CRM درخواست سبک موجود را با فرایند ticket موازی نکنید؛ یک inbox مرجع داشته باشید. |
| CRM بازاریابی | FluentCRM فقط در صورت نیاز به فهرست مشتری و automation ایمیلی | ادغام WooCommerce برای sync و automation دارد؛ ایمیل تبلیغاتی را فقط با opt-in و مدیریت لغو عضویت ارسال کنید. CRM بازاریابی جایگزین ticketing نیست. |
| چندفروشندگی | Dokan فقط وقتی فروشنده‌های مستقل، پنل فروشنده و تسویه‌ی چندفروشنده لازم است | برای فروشگاه تک‌فروشنده هزینه و سطح پیچیدگی بی‌دلیل ایجاد می‌کند. |
| اسلایدر/موشن | فعلاً نیاز به Revolution Slider یا GSAP نیست | هیرو و ریل محصول با CSS و JavaScript کوچک ساخته شده‌اند؛ از اسلایدر بزرگ برای محتوای ضروری استفاده نکنید. |

## قبل از انتخاب افزونه‌های عملیاتی

- درگاه، پیامک، اقساط و حمل‌ونقل را بر اساس سرویس قراردادشده‌ی فروشگاه انتخاب کنید؛ سازگاری و مستندات همان شرکت باید تأیید شود.
- سایت و افزونه‌های پولی را با لایسنس معتبر بگیرید؛ نسخه‌ی نال‌شده ریسک امنیتی و به‌روزرسانی دارد.
- کلید OpenRouter را فقط در پنل امن وارد کنید؛ endpoint رسمی در کد ثابت است. قبل از فعال‌سازی، هزینه، سیاست نگهداری داده و متن رضایت را با سیاست حریم خصوصی بهاران منطبق کنید. ساخت مقاله و توضیح محصول فقط پیش‌نویس می‌سازد. تبدیل JPEG/PNG به WebP در بارگذاری به پشتیبانی سرور وابسته است.
- پس از نصب cache/SEO/image plugins، صفحه‌ی محصول، سبد، checkout، حساب کاربری، پیام چت، cart count و تصاویر را با کاربر مهمان و واردشده بررسی کنید.
