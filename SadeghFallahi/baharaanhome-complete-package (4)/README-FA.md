# بهاران هوم | بسته‌ی نصب قالب فروشگاهی

این بسته شامل پوسته‌ی RTL ووکامرس، افزونه‌ی اختصاصی بهاران، فایل راهنمای نصب و فهرست کنترل طراحی است. قالب محصولات، قیمت، تصویر، دسته، ویژگی، موجودی، سبد و سفارش را از ووکامرس می‌خواند؛ اطلاعات نمونه‌ی تبلیغاتی به‌عنوان کالای واقعی وارد نمی‌شود.

## نصب

1. یک نسخه‌ی staging بسازید و پشتیبان کامل فایل‌ها و دیتابیس بگیرید.
2. WordPress 6.4+، PHP 8.0+ و WooCommerce را نصب کنید. روی سرور GD یا Imagick با WebP فعال باشد.
3. فایل `baharaan-home-theme.zip` را از مسیر نمایش ← پوسته‌ها نصب کنید.
4. فایل `baharaan-commerce-plugin.zip` را از افزونه‌ها ← افزودن نصب و فعال کنید.
5. واحد پول و نمایش تومان، درگاه پرداخت، حمل‌ونقل، صفحات سبد/پرداخت/حساب و سیاست‌های مرجوعی/حریم خصوصی را از ووکامرس و تنظیمات فروشگاه مشخص کنید.
6. دسته‌ها و ویژگی‌های سراسری (از جمله ویژگی `برند`) را بسازید. سپس محصولات را از محصولات ← افزودن یا ابزار CSV داخلی WooCommerce وارد کنید.
7. در «بهاران هوم» لینک‌ها و شماره‌های واقعی پشتیبانی را وارد کنید. ظاهر صفحه‌ی خانه، رنگ تأکید و موشن نیز از همین بخش قابل تنظیم است.

## امکانات پوسته

- صفحه‌ی اصلی فارسی با چیدمان مستقل، دسته‌ها و برندهای واقعی ووکامرس، ریل محصولات قابل کشیدن، جستجوی فروشگاه و مقاله‌های سایت.
- آرشیو فروشگاه و دسته با مرتب‌سازی و فیلترهای موجود در نسخه؛ کارت کالا با قیمت/موجودی ووکامرس و افزودن به سبد استاندارد.
- صفحه‌ی محصول با گالری، متغیرها، مشخصات ویژگی‌های محصول، دیدگاه‌ها، FAQ، مقایسه/علاقه‌مندی و نوار خرید موبایل.
- ساختار واکنش‌گرا، RTL، فونت‌های سیستمی، حرکت CSS سبک و پشتیبانی از تنظیم کاهش حرکت سیستم.
- محصولات فقط از کاتالوگ زنده‌ی ووکامرس نمایش داده می‌شوند؛ این بسته از فایل CSV رسمی ووکامرس برای ورود و برون‌بری کالا استفاده می‌کند.

## امکانات افزونه

- داشبورد اختصاصی و واکنش‌گرای مدیریت: آمار سفارش‌های اخیر، درخواست‌های پشتیبانی، آخرین سفارش‌ها، تاریخ شمسی در صورت وجود Intl و دسترسی سریع به محصولات/سفارش‌ها/CRM.

- پنل مدیریت اطلاعات کانال‌های تماس: تلفن، واتساپ، ایمیل، تلگرام، اینستاگرام، بله و ایتا.
- ویجت راهنمای خرید؛ در صورت واردکردن نام یا راه تماس، درخواست به CRM سبک پیشخوان می‌رود و با مرحله‌های جدید/در حال پیگیری/بسته مدیریت می‌شود.
- پاسخ راهنمای محصول با OpenRouter (خاموش پیش‌فرض)، کلید فقط سمت سرور، رضایت پیش از ارسال پرسش، نرخ محدودشده و پاسخ بر اساس داده‌های محصول منتشرشده. اطلاعات سفارش/CRM به مدل فرستاده نمی‌شود.
- ساخت پیش‌نویس مقاله و توضیح محصول از AI؛ خروجی مقاله با وضعیت Draft می‌ماند و خروجی محصول در متای پیش‌نویس ذخیره می‌شود. مدیر باید پیش از انتشار صحت محتوا را بررسی کند.
- ساخت پرامپت کاتالوگی تصویر از اطلاعات تأییدشده‌ی مدل و محصول. تصویر هوش مصنوعی خودکار ساخته نمی‌شود و باید با کالای واقعی تطبیق داده شود.
- تبدیل مشتق‌های تصویری وردپرس به WebP برای JPEG/PNG ثابت در صورت پشتیبانی Image Editor هاست؛ فایل اصلی حذف یا جایگزین نمی‌شود. GIF متحرک و فرمت‌های دیگر دست‌نخورده می‌مانند. کیفیت خروجی تنظیم‌پذیر است و تبدیل دسته‌ای رسانه‌های قبلی در این بسته نیست. پس از راه‌اندازی، تصویر، بندانگشتی، گالری و فرایندهای افزونه‌های رسانه را روی همان هاست بررسی کنید.
- تنظیمات عنوان و زیرعنوان خانه، رنگ تأکید، موشن و ارتباط‌ها؛ خروجی/ورودی JSON تنظیمات افزونه. کلید API عمداً از فایل خروجی حذف می‌شود و هنگام درون‌ریزی کلید فعلی حفظ خواهد شد.

## فعال‌سازی OpenRouter

در پنل بهاران هوم کلید API را وارد کنید، نام مدل فعال حساب OpenRouter را تعیین و پاسخ‌گویی AI را روشن کنید. هیچ کلیدی داخل JavaScript یا بسته قرار نداده‌ایم. OpenRouter یک سرویس بیرونی است؛ هزینه، دسترس‌پذیری، ماندگاری داده و متن حریم خصوصی را پیش از فعال‌سازی بررسی کنید. پنل آخرین شمارنده‌ی token گزارش‌شده را نشان می‌دهد، نه تخمین ریالی/دلاری هزینه. متن پرسش کاربر تنها پس از رضایت او ارسال می‌شود.

## درون‌ریزی/برون‌بری

- از پنل بهاران هوم، JSON تنظیمات همین افزونه را صادر یا وارد کنید.
- برای کاتالوگ، از محصولات ← همه محصولات ← برون‌بری/درون‌ریزی ووکامرس و فایل CSV استفاده کنید.
- این ZIP پشتیبان کامل وب‌سایت نیست: دیتابیس، رسانه‌ها، سفارش‌ها، کلیدها، افزونه‌های تجاری و محتوای اختصاصی فروشگاه را درون خود ندارد. برای انتقال کامل سایت از راهکار پشتیبان‌گیری معتبر و امن استفاده کنید.

## استک افزونه پیشنهادی

WooCommerce برای فروش؛ یکی از Rank Math یا Yoast برای SEO؛ یکی از LiteSpeed Cache (روی سرور LiteSpeed) یا WP Rocket؛ یک افزونه‌ی WebP/بهینه‌سازی مانند ShortPixel فقط اگر راهکار هاست کافی نیست. Elementor Pro، Dokan، CRM کامل و سرویس درگاه/پیامک فقط با نیاز واقعی و لایسنس رسمی اضافه شوند. از افزونه‌های کش، schema، جستجو یا مقایسه‌ی هم‌پوشان هم‌زمان پرهیز کنید. جزئیات در `PLUGIN-STACK-FA.md` است.

## وضعیت و محدودیت‌ها

در محیط ساخت، WordPress/WooCommerce و PHP CLI در دسترس نبودند؛ بنابراین نصب end-to-end، خروجی Lighthouse و خرید آزمایشی روی هاست واقعی انجام نشده است. قبل از انتشار، روی staging خرید مهمان/کاربر واردشده، محصولات متغیر، تصاویر WebP، سبد/پرداخت، بازیابی تنظیمات، موبایل، دسترس‌پذیری و سرعت را بررسی کنید. ارسال به API پیام‌رسان، ارسال پیامک، پرداخت/حمل‌ونقل یا اتصال ERP با ثبت آدرس تماس فعال نمی‌شود و به قرارداد/API سرویس مربوط نیاز دارد.
