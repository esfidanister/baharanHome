# سیستم طراحی بهاران هوم

## هدف

فضای فروشگاه باید برای خرید لوازم کوچک و کالاهای گران‌قیمت یکدست بماند: اطلاعات محصول در اولویت، زمینه‌ی گرم و آرام، رنگ سبز برای عمل‌های اصلی و رنگ طلایی فقط برای تاکید. عکس‌های واقعی محصول از خود کاتالوگ ووکامرس می‌آیند؛ جای خالی محصول با تصویر ساختگی کالا پر نمی‌شود.

## توکن‌های رابط

| توکن | مقدار پایه | کاربرد |
|---|---:|---|
| سبز عمیق | `#145C4F` | CTA، وضعیت فعال و لینک اصلی |
| سبز دوم | `#287B68` | جزئیات و تاکید ثانویه |
| زمینه کاغذی | `#F4F1E9` | فضای آرام هیرو و محتوای editorial |
| جوهر | `#172821` | متن اصلی |
| خاکستری آرام | `#65736B` | متن کم‌اهمیت |
| شامپاینی | `#C7A77C` | اشاره‌ی کم‌مصرف به کیفیت |
| خط | `#E7E5DC` | تفکیک کارت و فرم |
| گردی بزرگ | `18px` | کارت‌ها و پنل‌ها |

مدیر فروشگاه می‌تواند رنگ تأکید را از پنل تغییر دهد. فونت فعلی از Vazirmatn در صورت نصب و سپس Tahoma و فونت‌های سیستم استفاده می‌کند؛ فونت خارجی از CDN درخواست نمی‌شود.

## قواعد چیدمان

- صفحه‌ی اصلی در RTL و با فضای سفید روشن طراحی شده است. محصول منتخب از ووکامرس انتخاب می‌شود و کارت‌ها قیمت و موجودی را از خود محصول می‌خوانند.
- کارت محصول برای مقایسه‌ی سریع نام، تصویر، قیمت، نشان تخفیف واقعی ووکامرس، وضعیت موجودی، رتبه در صورت ثبت دیدگاه و اقدام‌های انتخاب را نمایش می‌دهد.
- صفحه‌ی محصول از گالری، تنوع، سبد و داده‌های خود ووکامرس استفاده می‌کند. مشخصات خالی پنهان می‌مانند.
- آیکون‌های دسته و رابط فایل SVG محلی هستند. لوگوی SVG و نسخه‌ی معکوس در `assets/images` قرار دارد؛ لوگوی سفارشی مدیر در هویت سایت وردپرس اولویت دارد.
- اندازه‌های `bh-product-card`، `bh-product-hero` و `bh-product-thumb` برای تصاویر آینده ثبت شده‌اند. فایل‌های قبلی برای این اندازه‌ها نیازمند بازسازی بندانگشتی در محیط وردپرس هستند.

## حرکت و دسترس‌پذیری

ریل محصول با drag و کنترل دکمه‌ای کار می‌کند؛ منوی موبایل دکمه‌ی باز/بسته و وضعیت aria دارد؛ جست‌وجوی زنده با صفحه‌کلید قابل مرور است؛ میانبر پرش به محتوا، focus قابل‌دیدن و حالت `prefers-reduced-motion` لحاظ شده است. حرکت با CSS و JavaScript کوچک انجام می‌شود و به GSAP، Swiper یا انیمیشن خارجی وابسته نیست.

این سیستم طراحی به‌تنهایی نتیجه‌ی دسترس‌پذیری یا سرعت را اثبات نمی‌کند. کنتراست، صفحه‌خوان، عرض ۳۶۰ پیکسل و Core Web Vitals باید روی نمونه‌ی اجرایی و محتوا/هاست واقعی اندازه‌گیری شوند.
