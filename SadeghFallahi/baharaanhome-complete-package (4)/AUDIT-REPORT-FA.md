# گزارش ممیزی و اجرای بهاران هوم

**نسخه‌ی بررسی‌شده:** پوسته‌ی 1.2.0 و افزونه‌ی 1.3.0؛ بسته‌ی نهایی هم‌نسخه با آخرین سورس تحویلی.  
**روش:** ممیزی کد قالب و افزونه، پنل مدیریت، JS/CSS و مستندات؛ بررسی نقاط ورود AJAX/مدیریت، اسکن ساختاری PHP، بررسی نحوی JS و صحت آرشیوهای ZIP. این جدول چارچوب ۲۰ تخصص است و نظرخواهی از افراد بیرونی نیست.

## گزارش آزمون و سازگاری

| آزمون | نتیجه | شواهد/حد |
|---|---|---|
| `node --check` برای JS پوسته و افزونه | موفق | `main.js`, `search.js`, `interactions.js`, `chat.js` بررسی نحوی شدند |
| ساختار ZIP قالب، افزونه، بسته‌ی کامل و سورس | موفق | `unzip -t` برای هر چهار آرشیو؛ ریشه‌ی دو ZIP نصب به‌ترتیب `baharaan-home/` و `baharaan-commerce/` است |
| `php -l` | تست‌نشده | PHP CLI در محیط ساخت نصب نیست؛ اسکن توازن delimiter و نام توابع تکراری انجام شد که جایگزین parser PHP نیست |
| فعال‌سازی روی WordPress/WooCommerce و محصولات متغیر | تست‌نشده | نصب WP/Woo در محیط ساخت وجود ندارد |
| WebP/JPEG/PNG و حفظ اصل رسانه | تست‌نشده روی هاست | کد به مسیر رسمی image editor واگذار می‌کند؛ GD/Imagick میزبان باید WebP داشته باشد |
| آزمون اتصال OpenRouter | تست‌نشده از این محیط | مدیر باید کلید و مدل فعال وارد کند؛ پنل دکمه‌ی آزمون دارد |
| سبد، checkout، حساب، HPOS | تست‌نشده end-to-end | سفارش‌ها از API ووکامرس خوانده می‌شوند و قالب سبد/پرداخت override نشده است |
| عرض موبایل/تبلت/دسکتاپ، صفحه‌خوان، Lighthouse | تست‌نشده | به محیط پیش‌نمایش، کاتالوگ و هاست واقعی نیاز دارد |
| import/export JSON و CSV محصولات | منطق کد/راهنما آماده؛ اجرای واقعی تست‌نشده | تنظیمات افزونه به JSON؛ محصول/وارییشن از CSV داخلی WooCommerce |

## مواردی که برای نصب واقعی لازم است

1. WordPress، WooCommerce، واحد/قالب قیمت تومان، درگاه و روش‌های حمل‌ونقل معتبر.
2. لوگوی نهایی (در صورت جایگزینی)، اطلاعات تماس، سیاست ارسال/مرجوعی/حریم خصوصی و ساعات واقعی پشتیبانی.
3. محصولات با SKU، تصاویر واقعی، دسته، برند و ویژگی‌های تاییدشده؛ Warranty و ارسال فقط در متای محصول پس از تایید.
4. کلید OpenRouter و نام مدل فعال، رضایت قانونی چت AI و بودجه‌ی درخواست‌ها.
5. درگاه، پیامک، پیک/شرکت حمل، CRM کامل، API پیام‌رسان یا ERP باید جداگانه با حساب/کلید سرویس مربوط راه‌اندازی شود.
6. نصب افزونه‌ی SEO/cache/optimizer منتخب با لایسنس؛ افزونه‌های تجاری در این ZIP نیستند.

## مرز بسته‌ی نصب

این بسته ZIP نصب پوسته و افزونه + سورس و مستندات است؛ image library، دیتابیس، سفارش/حساب کاربران، کلیدها، صفحات و افزونه‌های پولی را پشتیبان‌گیری نمی‌کند. Import/Export JSON فقط تنظیمات افزونه‌ی بهاران را انتقال می‌دهد؛ برای محصولات CSV رسمی WooCommerce و برای بکاپ کامل از راهکار پشتیبان‌گیری سایت استفاده شود.
