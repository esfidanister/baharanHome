# بهاران هوم — گزارش ممیزی بصری فاز ۱

تاریخ ممیزی: ۱۴۰۵/۰۸/۲۶  
دامنه: سورس موجود در `wp-content/themes/baharaan-home` و افزونه‌های اختصاصی، به‌علاوه تصویر وایرفریم پیوست‌شده.

## تفکیک درخواست و دستور مرجع

درخواست کاربر، پیاده‌سازی کامل وایرفریم و تجربه فروشگاهی Premium برای پروژه موجود وردپرس/ووکامرس است. متن طولانی پیوست‌شده به‌عنوان مشخصات محصول، محدودیت‌های داده و معیارهای پذیرش تفسیر شد؛ ادعای مشارکت متخصصان واقعی، کپی‌برداری از مراجع، داده ساختگی و تغییر هسته مجاز نیست.

## وضعیت واقعی پروژه

- پروژه یک نصب کامل WordPress با WooCommerce است.
- قالب فعال/موجود: `baharaan-home` با نسخه ۱.۲.۰.
- افزونه‌های اختصاصی: `baharaan-commerce` و `baharan-home-admin-dashboard`.
- قالب از RTL، لوگوی سفارشی، گالری WooCommerce، اندازه‌های تصویر، جست‌وجوی AJAX، کارت محصول، مقایسه/علاقه‌مندی و تنظیمات صفحه خانه پشتیبانی می‌کند.
- لایه بصری فعلی در چهار فایل CSS روی هم بارگذاری می‌شود: `main.css`، `brand-refresh.css`، `blue-final.css` و `design-system.css`.
- داده‌های محصول، قیمت، موجودی و لینک‌ها از WooCommerce خوانده می‌شوند؛ در سورس بررسی‌شده کالای ساختگی به قالب اضافه نشده است.
- Docker Compose تعریف شده است، اما در محیط فعلی اتصال به Docker Desktop با خطای Access denied برقرار نشد.
- ریشه پروژه Git repository نیست؛ بنابراین ثبت Git status واقعی در این محیط ممکن نبود. فایل‌ها بدون حذف یا overwrite تغییر نکرده‌اند.

## تحلیل وایرفریم پیوست‌شده

### مشاهدات مستقیم از تصویر

- ترکیب سه‌ستونه دارد: معرفی برند در سمت چپ، پیش‌نمایش دسکتاپ در مرکز، و پنل اجزای وایرفریم در سمت راست.
- هویت بصری حول Navy عمیق، آبی روشن و نارنجی کمپینی شکل گرفته است.
- هدر دسکتاپ سه لایه دارد: نوار خدمت، هدر اصلی با لوگو/جست‌وجو/اکشن‌ها، و ناوبری دسته‌بندی.
- Hero مرکز تصویر محصول بزرگ و فضای محیطی روشن دارد؛ متن فارسی در یک سطح آبی منحنی و CTA روشن قرار گرفته است.
- بعد از Hero، دسته‌بندی تصویری، دو بنر کمپینی، ریل محصولات، برندها، سکشن‌های خرید بر اساس فضا و فوتر تیره دیده می‌شود.
- موبایل ترکیب مستقل دارد: هدر کوتاه، جست‌وجو، Hero عمودی، دسته‌بندی افقی، پیشنهادهای کمپینی، ریل محصول و Bottom Navigation.
- پنل سمت راست، کتابخانه اجزا را نشان می‌دهد: هدر/مگامنو، Hero، دسته‌بندی، بنر، پیشنهاد ویژه، برند، لایف‌استایل، پرفروش‌ها، راهنمای خرید، خدمات، فوتر و Design System.

### استنباط طراحی

- وایرفریم یک صفحه خانه محصول‌محور با تنوع بصری کنترل‌شده است، نه یک گرید ساده WooCommerce.
- نارنجی باید به کمپین و تخفیف محدود بماند؛ آبی باید رنگ CTA و هویت اصلی باشد.
- Hero به تصویر تبلیغاتی محیطی نیاز دارد، اما تصویر SKU واقعی باید از تصویر تبلیغاتی جدا بماند.
- برای موبایل، تغییر ترکیب‌بندی لازم است و کوچک‌سازی مستقیم Hero دسکتاپ کافی نیست.

## شکاف فعلی با وایرفریم

1. Hero فعلی بیشتر یک ویترین محصول زنده با پس‌زمینه انتزاعی است؛ وایرفریم Hero محیطی/کمپینی با بنرهای مکمل دارد.
2. هدر فعلی دارای utility bar شرطی، جست‌وجو، حساب، سبد و mega menu است، اما نیاز به یکپارچه‌سازی بصری، رفتار sticky کنترل‌شده و نسخه موبایل مطابق وایرفریم دارد.
3. صفحه خانه فعلی سکشن‌های دسته، محصول، برند، editorial، مجله و خدمات دارد؛ Bento campaign، shop-by-room، limited offers معتبر، best sellers واقعی و section manager گسترده هنوز کامل نیستند.
4. تنظیمات فعلی مرکز مدیریت، انتخاب Hero، رنگ، سکشن‌های محدود و چند قابلیت محصول را پوشش می‌دهد؛ Header Builder، Banner Studio، Motion Studio و مدیریت ترتیب سکشن‌ها کامل نیستند.
5. چهار فایل CSS لایه‌ای باعث ریسک override و نگهداری سخت‌تر می‌شوند؛ پیش از توسعه بیشتر باید tokenها و ownership کامپوننت‌ها یکپارچه شوند.
6. نتیجه بصری واقعی در این فاز قابل تأیید نبود، چون Docker/WordPress runtime در دسترس نبود؛ Screenshot قبل/بعد و تست Playwright به محیط اجرای سایت نیاز دارد.
