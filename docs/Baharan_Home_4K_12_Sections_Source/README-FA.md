# بسته مرجع اجرایی ۴K بهاران هوم

این بسته شامل **۱۲ شیت مستقل با ابعاد ۳۸۴۰×۲۱۶۰** و فایل HTML هر بخش و دارایی‌های SVG اختصاصی است. تصاویر «طرح مفهومی و وایرفریم با جزئیات اجرایی» هستند، نه اسکرین‌شات سایت اجراشده و نه جایگزین تصاویر واقعی کالا.

## نحوه استفاده در Codex / Agent

۱. فایل‌های `png/01.png` تا `png/12.png` را به‌عنوان مرجع بصری جداگانه وارد کن. ۲. HTMLهای `html/` را برای معماری ظاهری و لایه‌بندی بررسی کن؛ این‌ها prototype مستقل‌اند، نه کد آماده قالب وردپرس. ۳. SVGهای `assets/` برای illustration هستند و جای تصویر محصول ثبت‌شده در ووکامرس را نمی‌گیرند. ۴. برای تولید قالب، اجزا را به WordPress Theme Templates/Gutenberg Patterns و WooCommerce Hookها تبدیل کن. ۵. با Chrome/Playwright در عرض ۳۶۰،۳۹۰،۴۳۰،۷۶۸،۱۰۲۴،۱۴۴۰ و ۱۹۲۰ تست بگیر. ۶. طراحی وب‌سایت اجرایی را به‌صورت واقعی با تصاویر مرجع مقایسه کن، بدون تولید محتوای تجاری ساختگی.

## هندسه و پیاده‌سازی

- عرض کانتینر دسکتاپ: حداکثر ۱۳۲۰ پیکسل (قابل تنظیم)، گاتر بیرونی در ۱۴۴۰ تقریباً ۶۰ پیکسل.
- پایه فاصله‌ها: ۴، ۸، ۱۲، ۱۶، ۲۴، ۳۲، ۴۸، ۶۴ پیکسل.
- رنگ‌ها: #0B2039 (سرمه‌ای)، #1769D2 (آبی)، #EAF3FF (یخی)، #F7F9FC (پس‌زمینه)، #FF8A3D (اکسنت).
- هدر: Utility ۳۶، Main ۸۸، Navigation ۵۶ پیکسل؛ Sticky فقط در صورت ثابت ماندن layout.
- هیرو: دسکتاپ ۶۲۰–۶۸۰ پیکسل؛ خروج محصول از لبه حدود ۸۰–۱۲۰ پیکسل بدون تجاوز از Viewport و بدون پوشاندن CTA.
- بنرها: زاویه‌دادن با border-radius نامتقارن و تزئینات SVG؛ از clip-path برای ماسک برخی پس‌زمینه‌ها استفاده کن و تصویر کالا را خارج از عنصر clipشده نگه دار.
- همه سکشن‌ها: عکس واقعی/کالای واقعی، RTL و کنترل صفحه‌کلید، حالت بدون داده، تصاویر responsive، و رعایت prefers-reduced-motion.
- هیچ ادعای ضمانت، تخفیف یا برند جعلی در انتشار نباید نمایش داده شود.

## ساختار

`png/`: PNGهای ۴K؛ `html/`: نمونه‌های مستقل قابل بازکردن در مرورگر؛ `assets/`: SVG برداری محصول (صرفاً illustration)؛ `sections.json`: فهرست بخش‌ها؛ `design-tokens.css`: استایل پایه.

**توجه:** خروجی ۴K رزولوشن فایل تصویر است؛ این خروجی‌ها بازآفرینی برداری/HTML با جزئیات بالا هستند، نه رندر فتوواقعی ۴K و نه اثبات دقت پیکسل‌به‌پیکسل اجرای نهایی وردپرس.
