# فاز ۹ — Admin Dashboard و Analytics

## وضعیت ممیزی و تکمیل

- داشبورد مدیریتی موجود بر پایه `wc_get_orders()` و APIهای رسمی WooCommerce کار می‌کند.
- KPIهای فروش، سفارش، سفارش‌های نیازمند رسیدگی، پردازش، تکمیل، لغو، بازپرداخت و موجودی از داده واقعی محاسبه می‌شوند.
- نمودار روزانه از سفارش‌های واقعی بازه انتخاب‌شده ساخته می‌شود.
- سفارش‌های اخیر و سفارش‌های نیازمند رسیدگی به صفحه مدیریت واقعی سفارش لینک دارند.
- محصولات کم‌موجودی از مقدار آستانه واقعی WooCommerce خوانده می‌شوند.
- پرفروش‌ها بر اساس آیتم‌های سفارش واقعی مرتب می‌شوند.
- بازه‌های امروز، هفته، ماه و سفارشی پشتیبانی می‌شوند.
- تاریخ شمسی در صورت وجود IntlDateFormatter و واحد پول از تنظیمات WooCommerce استفاده می‌شود.
- حالت خالی و نبود WooCommerce/مجوز مناسب بدون عدد ساختگی نمایش داده می‌شود.
- HPOS با استفاده از `wc_get_orders()` حفظ شده است.
- استایل داشبورد با هویت آبی بهاران و Responsive فعلی هماهنگ است.

## اعتبارسنجی

- PHP lint کل قالب و افزونه‌های اختصاصی: موفق.
- هیچ سفارش، فروش، محصول یا موجودی ساختگی اضافه نشد.
- تست زنده داشبورد و Screenshot به اجرای WordPress runtime نیاز دارد؛ Docker در محیط فعلی در دسترس نبود.
