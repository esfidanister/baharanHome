# فاز ۶ — Product Detail و Purchase Journey

## اجرا

- صفحه محصول با پنل اطلاعات روشن، کارت خرید و گالری Premium هماهنگ شد.
- دکمه بزرگ‌نمایی تصویر و Lightbox با بستن از طریق کلیک بیرون و Escape اضافه شد.
- گالری Thumbnail موجود حفظ شد و تصویر اصلی با lazy/eager مناسب کار می‌کند.
- فرم خرید اصلی WooCommerce و انتخاب تنوع‌ها دست‌نخورده باقی ماند.
- وضعیت موجودی، قیمت، تخفیف، SKU، امتیاز و CTA از داده واقعی محصول خوانده می‌شوند.
- نوار خرید چسبان موبایل و مشخصات فنی/FAQ/دیدگاه‌ها حفظ و از نظر بصری ارتقا یافتند.
- رنگ‌ها و CTA با Design System آبی بهاران هماهنگ شدند.

## اعتبارسنجی

- PHP lint کل قالب و افزونه‌های اختصاصی: موفق.
- JavaScript syntax check: موفق.
- خرید و تنوع محصول همچنان از منطق WooCommerce استفاده می‌کنند.
- تست تعاملی مرورگر و Screenshot واقعی به اجرای WordPress runtime نیاز دارد؛ Docker در محیط فعلی در دسترس نبود.

## وضعیت فاز

فاز ۶ از نظر سورس تکمیل شد.
